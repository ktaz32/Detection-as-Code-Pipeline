# DET-001 — Encoded PowerShell Execution

## Alert Description

This detection identifies PowerShell processes executed with encoded command-line parameters such as:

- `-enc`
- `-EncodedCommand`

Encoded commands are not inherently malicious, but they are frequently used by attackers to obscure PowerShell payloads and reduce command-line readability.

---

## MITRE ATT&CK

- **T1059.001 — Command and Scripting Interpreter: PowerShell**
- Tactic: Execution
- Related behavior: Defense Evasion

---

## Initial Triage

When this detection triggers, review:

1. Parent process
2. PowerShell command line
3. User account
4. Host
5. Execution timestamp
6. Source of the encoded command
7. Child processes
8. Network connections generated by PowerShell

---

## High-Risk Parent Processes

Prioritize investigation when PowerShell is launched by unusual processes such as:

excel.exe
outlook.exe
